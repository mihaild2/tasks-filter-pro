Brand lists

Each category has its own brand list; “All categories” is offered for every category. In the popup, the Brand suggestions are the shared list plus the lists of the selected categories.

Import / export

Export writes every list to a .json file. Import merges a file into the current lists (nothing is removed). Accepted: the exported format, { "<category id or name>": ["Acer", …] }, a plain JSON array (shared list), or a text file with one brand per line (goes into the selected list).

Collect from page

Reads the data.subject.brand column of the results table on an open Browswave tab and adds the brands to the list selected above.
